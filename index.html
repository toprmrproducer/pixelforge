Convert any image, instantly

A small, confident tool that converts images entirely in your browser — no uploads, no accounts, no waiting.

PixelForge converts image files from one format to another without ever uploading them anywhere. When you choose files, your browser decodes each image and redraws it onto a hidden canvas, then re-encodes that canvas into the format you pick. That's the same underlying technology browsers already use to display images, so conversion is fast and the result is a normal image file you can download straight away. Input supports almost any image your browser can display — JPG, PNG, WebP, GIF, BMP, AVIF, and SVG — plus two formats decoded on-device with a small helper library since browsers can't read them natively: iPhone HEIC/HEIFphotos and TIFF files (scans, some cameras). Output can bePNG,JPEG,WebP,GIF, orBMP. PNG/BMP are lossless, GIF is capped at 256 colors (best for flat graphics, not photos), JPEG and WebP are lossy with a quality slider to balance file size against sharpness. Transparent images flattened to JPEG or BMP are composited onto a background color you pick (white by default). You can convert multiple images in one batch, and each file is processed independently so one bad file won't stop the rest. After a file converts you can optionally crop, rotate, or resize it right here before downloading. Raw camera formats (CR2, NEF, ARW, DNG) aren't supported — they need proprietary demosaicing that can't run reasonably in a browser.
